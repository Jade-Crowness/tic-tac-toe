# 🍀 Tic Tac Toe       

## 🍀 Aim of The Project :    

I) Usage of Closure.    
II) Usage of Private Variables.     
III) Usage of Factory Functions.    
IV) Usage of Module Patterns or IIFE.   

## 🍀 Logic and Tasks of The Project :     

I) Create a gameboard which will contain the players as private variables. (🍀)     
II) Create an array which correspondes to the winning condition. (🍀)     
III) create a function method inside IIFE which lets "X" or "Y" placed upon the cell while clicking on it and does not let the player to change the value by clicking on it again. (🍀)   
IV)  Check for winner. (🍀)      
V) Changing the winning cell background color to indicate winning player. (🍀)      
VI) Adding a restrart button. (🍀)      
VII) Finalizing html and css design. (🍀)

Mac Os and Windows : High   
Others : Low - Medium
