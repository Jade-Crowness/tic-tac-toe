# Tic Tac Toe       

## Aim of The Project :    

I) Getting Understanding of Closure.    
II) Getting Understanding of Private Variables.     
III) Getting Understanding of Factory Functions.    
IV) Getting Understanding of Module Patterns or IIFE.   

## Logic and Tasks of The Project :     

I) Create a gameboard which will contain the players as private variables. (ﾒ)     
II) Create an array which correspondes to the winning condition. (ﾒ)     
III) create a function method inside IIFE which lets "X" or "Y" placed upon the cell while clicking on it and does not let the player to change the value by clicking on it again. (ﾒ)   
IV)  Check for winner. (ﾒ)
